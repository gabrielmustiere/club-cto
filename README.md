# Club CTO de Nantes

Site vitrine de la communauté des CTO et leaders tech nantais.

## Lancer le site en local

Le projet est un simple fichier `index.html` statique. N'importe quel serveur HTTP fait l'affaire.

### Avec Node.js

```bash
npx serve .
```

Ou avec le serveur HTTP intégré :

```bash
npx http-server . -p 3000
```

Puis ouvrir [http://localhost:3000](http://localhost:3000).

### Avec Python

```bash
python3 -m http.server 3000
```

### Avec PHP

```bash
php -S localhost:3000
```
